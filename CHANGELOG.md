# Changelog

## 1.1.0

- adicionada descoberta recursiva de árvores em `TDirectory`;
- adicionada catalogação universal das chaves ROOT;
- adicionadas categorias para objetos suportados pelo JSROOT;
- adicionada seleção de múltiplos arquivos;
- separada a aplicação em módulos de domínio, aplicação, infraestrutura e
  apresentação;
- removida a construção de relatório com `innerHTML`;
- adicionados exportador CSV seguro e testes automatizados;
- fixada a dependência JSROOT em 7.11.0.
